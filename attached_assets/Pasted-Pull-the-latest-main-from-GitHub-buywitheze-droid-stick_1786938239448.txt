Two behaviour changes worth knowing about:
  1. The upload error toasts changed. The translation keys toast.networkError and
     toast.networkErrorDesc are gone, replaced by toast.uploadNetworkDesc,
     toast.uploadServerBusyDesc and toast.uploadFileGoneDesc in en, es and fr. A
     failure from the /api/prepare-raster-upload endpoint now says the service was
     busy instead of blaming the customer's internet. The server route itself is
     unchanged.
  2. Large images are now decoded in the browser on capable desktops instead of
     being POSTed to /api/prepare-raster-upload, so that endpoint should see less
     traffic. Nothing server-side needs changing.
