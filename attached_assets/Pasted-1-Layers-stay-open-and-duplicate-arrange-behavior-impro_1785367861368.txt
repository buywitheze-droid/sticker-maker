17. Fix Sharp’s synthetic 72-DPI PNG value
Commit: 7fcef88 Treat metadata-free PNGs as 300 DPI

Changed:

server/routes.ts
.agents/memory/raster-upload-dpi.md
Root cause fixed:

PNGs without a pHYs chunk have no real embedded DPI.
Sharp reports a default density: 72 for these files.
The app was mistakenly treating that synthetic 72 value as real metadata.
Implementation:

Added real PNG pHYs chunk detection.
Metadata-free PNGs now return 300 DPI.
Real embedded PNG DPI remains respected, capped at the application’s supported maximum.
Verified with:

Cousinfront: 3417×4923, density 300
cousin_back: 3055×5268, density 300

19. Fix Layers copies stacking in one vertical line
Commit: e3b91c4 Pack layer copies across the full sheet

Changed:

client/src/components/image-editor/image-editor-provider.tsx
client/src/components/image-editor/useImageEditorModelArrangeKeyboard.ts
client/src/components/image-editor/useImageEditorModelStateDesign.ts
.agents/memory/MEMORY.md
.agents/memory/copy-count-arrangement.md
Root cause fixed:

Increasing a Layers copy count selected the new copies.
Auto-Arrange interpreted that as “arrange selected designs only.”
All other designs were treated as fixed obstacles.
The new copies therefore stacked below the source design.
Implementation:

Added an arrangeAll option to Auto-Arrange.
Layers copy-count changes now call:
bag.handleAutoArrangeRef.current({
  skipSnapshot: true,
  preserveSelection: true,
  arrangeAll: true,
});

Behavior:

Copy changes now repack the entire sheet.
Designs fill space across and down.
Gangsheet height expansion still works.
The copied layer remains selected.
A second click on Auto-Arrange is no longer required.
20. Shrink selection handles and rotation zones at low zoom
Commit: 2a84434 Shrink selection controls at low zoom

Changed:

client/src/components/preview-section.tsx
.agents/memory/MEMORY.md
.agents/memory/low-zoom-selection-controls.md
Root cause fixed:

Handles used inverse zoom scaling.
When the whole sheet was fit into view, the handles and rotation hit zones appeared disproportionately large.
The rotation ring could activate when clicking in the design interior.

function getLowZoomHandleScale(zoom: number): number {
  return zoom < 1 ? 0.25 : 1;
}

Single-design resize handles.
Single-design rotation hit zones.
Multi-selection resize handles.
Multi-selection rotation hit zones.
Visible single-design corner controls.
Visible multi-selection corner controls.
Behavior:

Below 100% zoom: controls are 25% of their previous size.
At 100% zoom and above: existing behavior is unchanged.
Rotation no longer triggers across an oversized center-area zone.
